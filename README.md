# 傳承 Beta 0.9.23 Hotfix 2【能力點倍率降載與輪迴之門】

本版以 Beta 0.9.23 Hotfix 1 為底包，主要修正攻擊能力點倍率爆炸、降低戰鐮覺醒副本難度，並將戰鐮覺醒升格為第一部終局入口。

## 能力點倍率降載

Hotfix 1 的攻擊能力點採用每點 ×1.08，後期點數過多時會造成倍率失控。

本版改為：

```text
攻擊倍率 = 10 ^ (攻擊能力點 / 700)
```

保留能力點重置按鈕與舊存檔相容，已投入點數不會消失。

## 戰鐮覺醒副本調整

【收割試煉者】不再使用玩家攻擊 ×8 作為攻擊力，避免玩家越強 Boss 越容易一掌秒殺玩家。

調整後：

```text
血量：玩家最大生命 ×18
攻擊：玩家最大生命 ×18%
防禦：玩家防禦 ×3
回血：最大生命 0.2%/秒
攻速：1.2/秒
限時：120 秒
```

## 戰鐮終局覺醒條件

戰鐮覺醒新增條件：

```text
已覺醒滿 9 個職業
```

戰鐮自身不計入這 9 個職業。此設定用來讓戰鐮成為第一部最後的輪迴鑰匙。

## 輪迴月圓與輪迴之門

戰鐮覺醒成功後：

```text
覺醒為【收割者】
獲得稱號【輪迴月圓】
解鎖【輪迴之門】
```

【輪迴月圓】會寫入輪迴紀錄，可帶入第二部【輪迴】。

【輪迴之門】會出現在收納選項最下面。此版本只做第二部入口預覽，不會清除玩家存檔。

## 相容性

舊存檔可直接使用。若玩家已經完成戰鐮覺醒，會自動補發【輪迴月圓】並解鎖【輪迴之門】。
