本修正版整理 0.9.7 的升階體驗與 UI。玩家升階成功後會進行完整轉生：等級、經驗、地圖關卡、裝備、養成欄與能力點會重置，已投入養成會壓縮成階段潛能。

## Beta 0.9.7 鏡像門神與裝備養成

本版新增裝備升星、突破、玩家階段、升階副本「鏡像門神」、混合副本與材料系統。

- 鏡像門神會使用進場前玩家數值快照生成，不會因戰鬥中玩家變強而同步變強。

- 金幣/經驗副本每 24 小時刷新 3 次進入機會。

# 傳承 Beta 0.9.6 刺盾、後援與稱號系統

本版以 Beta 0.9.5 戰鐮恐懼版為基底，新增三個大型系統：刺盾職業、寵物後援與稱號面板。

## 更新重點

- 新增史詩職業「刺盾」與專武「無敵龜殼」。
- 刺盾無法主動攻擊，血量 +5000%、防禦 +500%，每秒恢復最大生命 1%。
- 新增刺盾專屬「荊棘」反傷：受到傷害堆層，每層提高反傷。
- 無敵龜殼：荊棘反傷後 20% 機率嘲諷目標，冷卻 5 秒。
- 新增嘲諷：目標傷害 / 防禦 / 回血 -60%，攻速 +50%，持續 10 秒且可疊秒。
- 新增寵物後援系統，Lv100 解鎖，可在 🐱 貓與 🐶 狗之間多選一出戰。
- 貓：高攻速後援，5% 機率施加獨立撕裂。
- 狗：恐懼後援，10% 機率施加恐懼，與戰鐮恐懼共用層數與效果。
- 新增稱號系統與稱號面板，包含屬性加減、被動增益、負面效果與稱號清單。

# 傳承 Beta 0.9.4 獨立關卡版

本版以 Beta 0.9.3 成功版為基底，新增「地圖獨立關卡」：起源主線與森林不再共用同一個關卡進度。主城推進到第 100 關時，森林仍會讀取森林自己的關卡，第一次進入森林預設從第 1 關開始。

# 傳承 Beta 0.9.3 數字與狙擊步槍熱修版

本熱修版修正三個測試問題：大數字未縮寫、燙手的狙擊步槍新被動未穩定生效、戰鬥放大文字造成 UI 爆版與卡頓。

狙擊步槍目前只保留新被動：目標當前生命低於目標最大生命 30% 時直接秒殺，普通怪、精英怪、Boss 都可觸發。

# 傳承 Beta 0.9.3 職業專武被動修正版

本版更新狂戰、戰騎、戰鐮、刺客、法師、弓箭手、盜賊、槍手等職業 / 專武被動，並將暗黑手套與魔法手套的專武等級拆開保存。

重點：戰騎秒殺加入 15 秒冷卻；槍手改為 30% 血量處刑線；戰鐮鐮刀新增恐懼逃離；法師元素法杖新增漩渦；暗黑手套與魔法手套不再共用同一個 glove 等級。

# 傳承 Beta 0.9.2 狀態單位熱修版

本版修正技能師七選一狀態的顯示與堆疊邏輯：擊暈、禁錮、混沌改為秒數型，破甲與虛弱改為百分比型，中毒、撕裂、燃燒維持層數型，並新增 500 層門檻爆發效果。


本版基於 Beta 0.9.1 召喚師戰鬥熱修版，新增「浮空」玩家狀態與「技能師 / 傳說」職業。

重點：技能師關閉普攻，改用特殊狀態傷害；每次攻擊只會從 7 種狀態中隨機選 1 種施加；低血量自動浮空免疫並回血；專武魔法手套會讓本次被選中的狀態堆層翻倍。

# 傳承 Beta 0.9.1 大型系統修正版

本版以 Beta 0.9.0 平衡修正版為基底，加入大型平衡與系統更新。

- 強化石礦坑：70 關解鎖。
- 裝備強化：只有 +10、+20 等十階突破需要強化石，其餘只消耗金幣。

- 深淵不再顯示倒數 0 秒，無挑戰時間限制。
- 神器強化只消耗金幣。
- 怪物面板加大，降低狀態顯示造成的畫面跳動。

## Beta 0.9.5 戰鐮恐懼狀態

- 新增戰鐮專屬狀態【恐懼】：普攻命中後 45% 機率施加 1 層，最高 300 層。
- 恐懼每秒造成目標最大生命值 0.1% 傷害；若因此死亡，正常給予死亡獎勵。
- 恐懼達 100 / 200 / 300 層時，分別觸發 20% / 25% / 30% 逃離判定，每個門檻只判定一次。
- 恐懼逃離不算死亡，不給金幣、經驗、強化石、裝備、傳承之魂或任何擊殺獎勵。
- 三次逃離判定都失敗後，目標進入恐懼崩潰：攻速 / 回血 -40%，無法使用技能，持續到戰鬥結束。

## 傳承 Beta 0.9.6 Hotfix：Boss恐懼與飄字優化
