# 傳承 Beta 0.9.23 Hotfix 1【能力點重置與覺醒面板整理】

本版以 Beta 0.9.23【逐日者覺醒】為底包，主要處理後期能力點與覺醒 UI 的整理。

## 能力點重置

新增【重置能力點】按鈕，位於能力點面板底部。

重置後：

- 已投入的能力點全部歸零。
- 已使用點數全數返還為可用能力點。
- 不影響玩家等級。
- 不影響職業等級。
- 不影響覺醒、裝備、神器、天域、下獄與副本進度。

## 攻擊能力點倍率化

攻擊能力點不再是固定 +2。

新規則：

- 每 1 點攻擊能力點，攻擊倍率 ×1.08。
- 舊存檔原本投入的攻擊能力點會自動轉換。
- 面板會顯示攻擊強化等級與目前倍率。

## 覺醒面板整理

已覺醒職業會收起覺醒條件與副本入口，避免已畢業職業還掛在待辦清單。

新增【已完成覺醒總覽】，可查看已覺醒職業、副本與稱號紀錄。

## 逐日者稱號修正

【一箭看不見】修正為紅色稱號顯示。

## 相容性

保留舊存檔相容。保留 0.9.23 逐日者與 0.9.22 Hotfix 6 下獄修正。
