# 傳承 Beta 0.5.6 攻擊演出系統

本版以 Beta 0.5.5 完整專案為基底，重做玩家武器攻擊演出。

## 更新重點
- 移除武器永久顯示、右下固定、漂浮與跟隨畫面的舊實作。
- 新增獨立武器系統：`weaponConfig.js`、`weaponRenderer.js`、`attackAnimation.js`。
- 平常不顯示武器與手，只有攻擊瞬間顯示。
- 武器素材全部使用 `assets/weapons/` 內 PNG。
- 木劍、鐵劍、巨劍、鐮刀、破雲槍、戰天斧皆有不同攻擊動畫。
- 保留原有怪物震動、傷害數字、爆擊、秒殺、狀態、編隊、掉落與裝備邏輯。
- 存檔相容，未改動存檔資料結構。

## 未來擴充
`weaponConfig.js` 已保留法杖與弓箭掛點，日後新增素材與動畫即可擴充。
