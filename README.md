# 傳承 Beta 0.9.24 Hotfix 2【輪迴入口接線修正】

本版以 Beta 0.9.24 Hotfix 1【輪迴模式重構與下獄怪物】為底包，集中修正輪迴入口與死亡繼承介面的接線問題。這次不是改玩法規則，而是把已經定案的輪迴模式入口、職業選擇、死亡三選一面板接起來，避免按鈕像幽靈門鈴一樣按了沒反應。

## 本版重點

- 修正【踏入輪迴】按下後沒有反應的問題。
- 點擊輪迴之門後，會正確進入五職業選擇。
- 五個輪迴職業維持：技能師、戰鐮、狂戰士、槍手、弓箭手。
- 選完職業後會直接進入《傳承》主戰鬥畫面，從【輪迴・下獄 1-1】開始。
- 補上輪迴死亡後三選一面板接線。
- 死亡三選一維持：能力繼承、裝備繼承、資源繼承。
- 修正輪迴狀態、開箱、地圖選擇、技能點升級等面板可能打不開的問題。
- 活著時仍不能回上一世，只有死亡流程中才可回上一世。

## 保留內容

- Beta 0.9.24 補齊的法師、刺客、戰騎三個覺醒。
- 戰鐮 9 覺醒條件、【輪迴月圓】與輪迴之門。
- Beta 0.9.24 Hotfix 1 的輪迴主戰鬥模式與下獄怪物表 V0.1。
- 輪迴寶箱掉落：小怪 1-3、精英 3-4、小 Boss 5、Boss 10。
- 輪迴地圖打完 1-30 後不自動跳圖。
- Beta 0.9.23 Hotfix 2 的能力點倍率降載與戰鐮試煉調整。
- 逐日者覺醒與紅色稱號修正。
- 下獄 Hotfix 6 狀態同步。
- 攻速 100/秒上限與手機降溫保護。

## 測試重點

1. 點【輪迴之門】。
2. 點【踏入輪迴】。
3. 應出現五職業選擇。
4. 選職業後應進入主戰鬥畫面。
5. 角色死亡後應出現繼承三選一。
