# 傳承 Beta 0.7.0 職業與專武系統

本版以《傳承 Beta 0.6.0 森林狀態壓迫與優先目標》為基底修改，保留舊存檔與既有森林壓迫系統，新增職業、專武、專武獨立養成，以及依地圖動態切換的優先打擊目標。

## 更新重點

### 職業系統
- 初始職業：⚔️ 戰士。
- 進階職業可自由切換：
  - 🪓 狂戰士：Lv50 解鎖，專武為戰斧類。
  - 🐎 戰騎：Lv100 解鎖，專武為長槍類。
  - 🩸 戰鐮：Lv150 解鎖，專武為鐮刀類。
- 未解鎖職業會顯示等級需求，不能提前切換。

### 職業被動
- ⚔️ 戰士：無專武、無被動。
- 🪓 狂戰士：增強燃燒與撕裂傷害，玩家造成的撕裂可無限疊加。
- 🐎 戰騎：增強破甲，普通攻擊有 50% 機率打出無視防禦傷害，秒殺率提升至 10%。
- 🩸 戰鐮：普通攻擊必定攻擊最多 3 個目標，增強撕裂傷害，玩家造成的撕裂可無限疊加。

### 專武系統
- 新增職業專武欄。
- 只顯示目前選中職業的專武。
- 戰士沒有專武。
- 狂戰士顯示戰斧專武，戰騎顯示長槍專武，戰鐮顯示鐮刀專武。
- 專武等級分開保存，不會互相繼承。
  - 例如戰斧專武 Lv5，切換到戰鐮後，鐮刀專武仍是自己的等級。

### 優先目標修正
- 優先打擊目標改為依照目前地圖動態顯示。
- 起源主線只顯示：自動 / 🪵 / 👹 / 🌳。
- 森林只顯示：自動 / 🐇 / 🐂 / 🦖 / 🦕。
- 每張地圖各自記錄自己的優先目標，不再出現主城還能選森林怪物的問題。

## 保留內容
- 保留 Beta 0.6.0 森林狀態壓迫。
- 保留怪物群共同攻擊。
- 保留蠻牛震盪暈眩。
- 保留兔子狂咬、暴龍撕裂、古龍最大生命 5%/秒回血。
- 保留玩家破甲每 10 關重置。
- Save Key 不變，舊存檔可延續。

## 測試建議
- 主城確認優先目標只出現 🪵 👹 🌳。
- 森林確認優先目標只出現 🐇 🐂 🦖 🦕。
- Lv50 測狂戰士，Lv100 測戰騎，Lv150 測戰鐮。
- 確認專武升級等級不會跨職業繼承。
