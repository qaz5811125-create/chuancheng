# 傳承 Beta 0.9.24 Hotfix 1【輪迴模式重構與下獄怪物】

本版以 Beta 0.9.24【終局覺醒與輪迴雛形】為底包，重構輪迴入口與玩法呈現，移除原本像測試展示櫃的輪迴雛形介面，改成進入輪迴後直接使用《傳承》主戰鬥畫面打怪、受傷、飄字、推關與開箱。

## 本版重點

- 輪迴之門進入後改為真正【輪迴模式】。
- 輪迴不再用純展示面板推關，改接回主戰鬥畫面，保留攻擊、命中、受傷、浮動傷害與打擊感。
- 活著時不能返回上一世。
- 只有死亡後才會進入輪迴死亡流程，並可選擇繼承或死亡後回到上一世。
- 修正死亡後三選一規則：不是三選一職業，而是三選一繼承。
  - 能力繼承：保留部分能力 / 屬性 / 成長數值。
  - 裝備繼承：保留一件裝備 / 武器 / 核心裝備成果。
  - 資源繼承：保留寶箱 / 技能點等命運資源。
- 繼承後下一世死亡不能再次繼承，要等到再下一世才重新開放。
- 輪迴職業仍固定五個：技能師、戰鐮、狂戰士、槍手、弓箭手。
- 輪迴地圖打完 1-30 後不自動跳圖，若玩家沒有手動選擇下一張地圖，會繼續刷目前地圖 1-30。
- 新增輪迴寶箱怪物掉落：小怪 1-3、精英 3-4、小 Boss 5、Boss 10。
- 實裝輪迴・下獄怪物表 V0.1。

## 輪迴・下獄 V0.1

地圖主題：囚禁、鎖鏈、審判、死亡、逃出生死第一層。

地圖機制：

- 無法回血。
- 無法復活。
- 一條命走到底。
- 死亡後退出下獄，進入輪迴死亡三選一。
- 怪物偏向控制、禁錮、封鎖、壓迫。

怪物：

- 小怪：鎖魂囚兵 ⛓️💀，攻擊附帶禁錮，降低玩家閃避。
- 小怪：獄火殘魂 🔥👻，造成燃燒，死亡後小範圍爆炸。
- 精英：鐵刑獄卒 🪓👹，高防禦守衛。
- 精英：魂鏈審問官 ⛓️🧙，封鎖技能並延長負面壓力。
- 小 Boss：下獄判官 ⚖️💀，依玩家輪迴死亡次數提升能力。
- 小 Boss：典獄長・摩洛 🔥⛓️👑，鎖血、召喚囚魂、低血狂暴方向。
- 第 30 關仍依輪迴規則生成傳承職業 Boss。
