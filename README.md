# 傳承 Beta 0.9.22 Hotfix 3【下獄強制建迷宮】

本版基於 Beta 0.9.22 Hotfix 2 製作。

## 本版重點

- 修正下獄誓約點擊後仍顯示 no-run 的問題。
- 改用 Hotfix 3 強制建迷宮入口。
- 下獄 run 直接建立，不再依賴舊 startHell / isDungeon 判定。
- 進入下獄時立即生成 2～3 扇隨機門。
- 地圖維持隨機，不是固定路線。
- 保留 Hotfix 1 的攻速 100/秒上限與高攻速降溫保護。

## 測試重點

1. 點擊四種誓約是否都能進入迷宮。
2. 進入後是否出現 2～3 扇門。
3. 重新整理或重進後，下獄進度與職業鎖定是否正常。
4. 換職後是否觸發誓約斷裂。
5. 多次重新開始時，門提示與房間組合是否有隨機變化。

# 傳承 Beta 0.9.21【天域開門】七女神免死修正

本熱修修正天域第100關七女神免死異常。七女神現在只會依規格觸發「1% 鎖血」，不會回滿血復活，也不會在死亡後被回血或生命成長拉回場上。

修正重點：
- 七女神不再吃一般怪物【復活】。
- 每位七女神免死次數硬性封頂 2 次。
- 免死觸發時只保留 1% 血量並鎖血 20 秒。
- 免死耗盡後真正死亡，不會被回血、生命成長、舊死亡流程再次拉起。
- 主神召喚出的女神死亡後，也會從主神召喚池移除。

# 傳承

## Beta 0.9.20【世界之王？】

本版以 Beta 0.9.19【過熱保護】為基底，新增技能師覺醒：技能師 →【天師/獄使】。

### 新增

- 新增技能師覺醒條件：技能師職業等級 Lv.5、通關【世界之王？】。
- 新增雙型態覺醒職業：【天師/獄使】。
- 覺醒後可自由切換天師與獄使型態。
- 新增天師被動：強攻、殘血鎖血、瀕死復活、第四次強化普攻。
- 新增獄使被動：週期無敵、鎖血、無視防禦傷害、三階段復活、護盾。
- 新增天師技能【以天為棋】。
- 新增獄使技能【以地為局】。
- 新增共用專武等級：天師【神權劍】、獄使【亡靈鎖】。
- 新增覺醒副本【世界之王？】。
- 新增 Boss：諾麗（傀儡）🧟‍♀️。
- 新增 Boss 被動：三次復活。
- 新增 Boss 技能【亡靈進行曲】：召喚三隻隨機地圖 Boss，諾麗在召喚 Boss 死亡前無敵。
- 新增副本壓制【情感動搖】：每秒增加 0.5% 猶豫值，每 10% 使玩家狀態施加率 -5%，最高 -50%。

### 保留

- 保留 Beta 0.9.19【過熱保護】全部內容。
- 保留通天盜、天之王•神兵、魔戰神、終幕槍神、收割者等既有覺醒資料。
- 保持舊存檔相容。


## Beta 0.9.21【天域開門】

- 開啟世界地圖【天域】，Lv200 進入。
- 天域為 101 關挑戰模式，通過第 101 關後自動返回主世界，可重複進入。
- 天域所有關卡無時間限制。
- 進入天域時畫面變暗 5 秒，第 1 秒顯示：「你為何來到這裡...」。
- 新增地圖壓制【神威壓制】：玩家狀態施加率降低、回血效果降低。
- 天域怪物免疫控制類狀態。
- 新增小兵、中將、主將、戰神、七女神、護法與主神。
- 第 100 關為七女神 + 戰神大型編隊，第 101 關為主神 + 雙護法。
- 主神召喚女神時，被擊殺過的女神不會再次被召喚。
- 天眼審判者【審判】為 10 秒暫時拔除效果。
