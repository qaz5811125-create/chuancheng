# 傳承 Beta 0.5.8 世界地圖、森林與怪物攻擊系統

本版以 Beta 0.5.7 命中回饋與連擊系統為基底修改，保留舊存檔與既有系統，新增世界地圖、森林地圖、玩家生存屬性與怪物主動攻擊。

## 更新重點
- 新增世界地圖頁籤，顯示森林、沙漠、海域、天域、下獄。
- 森林 Lv50 正式開啟；沙漠 Lv100、海域 Lv150、天域 Lv200、下獄 Lv250 先顯示鎖定與敬請期待。
- 新增森林怪物：🐇 森林野兔、🐂 森林蠻牛、🦖 森林暴龍、🦕 森林古龍。
- 森林 Boss 會隨機出現 🦖 高攻擊高破甲型，或 🦕 高防禦高回血型。
- 新增玩家血量、防禦、回血/秒，初始為 HP 10000、防禦 500、回血 500/秒。
- 玩家血量、防禦、回血可用金幣與能力點升級。
- 新增怪物主動攻擊玩家，怪物攻擊力、破甲與攻速會隨關卡成長。
- 新增怪物技能：狂暴、擊飛、撕咬、無敵。
- 新增玩家狀態：暈眩、撕裂、降防、破甲。
- 玩家暈眩時不能攻擊，且不能回血。
- 玩家血量歸零時會觸發簡易戰鬥失敗流程，重置目前關卡戰鬥。
- 保留 Beta 0.5.7 的命中特效、連擊系統與怪物詞綴系統。
- 保留攻擊、自動攻擊、傷害數字、爆擊、秒殺、狀態、編隊、掉落、裝備、強化、技能、副本、離線收益與舊存檔相容。

## 存檔
- Save Key 不變，舊存檔可直接延續。
- 舊存檔若沒有血量、防禦、回血、世界地圖或玩家狀態欄位，會自動補上預設值。
- 版本號更新為 Beta 0.5.8。
