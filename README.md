# 傳承 Beta 0.5.0 Test

手機 GitHub + Netlify 自動部署版本。

## 本版新增

- 離線掛機系統
- 離線時間最高累積 8 小時
- 離線收益包含金幣、經驗、傳承之魂、裝備
- 離線期間不推進主線，只重複刷離線前所在關卡
- 領取收益視窗
- 背包不足時自動捨棄超出裝備並提示
- Save Version 升級至 0.5.0

## 更新方式

1. 解壓縮 ZIP。
2. 將裡面的檔案全部上傳到 GitHub Repository 根目錄。
3. Commit changes。
4. Netlify 會自動部署同一個網址。

請不要直接上傳 ZIP 本體。
