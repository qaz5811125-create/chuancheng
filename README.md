# 傳承 Beta 0.9.24 Hotfix 4【輪迴戰鬥接線修正】

本版以 Beta 0.9.24 Hotfix 2【輪迴入口接線修正】為底包，集中修正輪迴進入後仍顯示上一世資料的問題。輪迴不再沿用第一部能力點、養成、裝備、背包、神器、後援與覺醒職業顯示。

## 本版重點

- 輪迴中隱藏第一部能力點、養成、裝備、背包、自動分解、神器、後援與稱號面板。
- 輪迴 HUD 改成輪迴專用資訊。
- 輪迴職業只顯示五個未覺醒職業之一。
- 修正技能師進輪迴仍顯示【天師 / 獄使】的問題。
- 輪迴中遮蔽第一部覺醒效果、專武、神器與裝備加成。
- 新增輪迴專用收納面板。
- 新增輪迴六格裝備欄：武器、頭盔、戒指1、戒指2、項鍊、鞋子。
- 輪迴裝備可以更換與卸下。
- 開寶箱取得的裝備會進入本世輪迴背包，空槽自動裝第一件。
- 右側收納選單在輪迴中只顯示輪迴操作。

## 輪迴隔離規則

輪迴中不直接使用第一部資料。只有死亡後三選一選到的繼承類型，才會把對應部分帶入下一世。

死亡三選一維持：

1. 能力繼承
2. 裝備繼承
3. 資源繼承

## 保留內容

- Hotfix 2 的輪迴入口修正。
- Hotfix 1 的輪迴主戰鬥模式與下獄怪物表 V0.1。
- 輪迴寶箱掉落：小怪 1-3、精英 3-4、小 Boss 5、Boss 10。
- 輪迴地圖打完 1-30 後不自動跳圖。
- Beta 0.9.24 補齊的法師、刺客、戰騎覺醒。
- 戰鐮 9 覺醒條件、【輪迴月圓】與輪迴之門。
- 舊存檔相容。

## 測試重點

1. 進入輪迴後，確認第一部能力點 / 養成 / 裝備欄沒有出現。
2. 確認輪迴職業顯示為未覺醒職業。
3. 開輪迴寶箱取得裝備後，確認裝備可更換。
4. 打開右側收納，確認只剩輪迴相關功能。
5. 死亡後確認繼承三選一仍正常。


## 傳承 Beta 0.9.24 Hotfix 4【輪迴戰鬥接線修正】

- 修正輪迴中手動攻擊失效。
- 修正輪迴中自動攻擊失效。
- 新增輪迴戰鬥數值橋接，攻擊 / 攻速 / 暴擊 / 防禦 / 回血改讀輪迴本世資料。
- 保留輪迴資料隔離，不讓第一部裝備、覺醒、神器與養成偷渡到第二部。
- 確保輪迴・下獄怪物可正常受傷、死亡、掉寶箱並推進關卡。
