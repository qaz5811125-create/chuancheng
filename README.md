# 傳承 Beta 0.9.16【覺醒試煉重鑄】

本版以 Beta 0.9.15【天之王•神兵】為基底，修正覺醒副本進場瞬間秒殺 Boss、直接通關的問題。

## 更新重點

- 新增覺醒 Boss 標準強度規格：血量改為「玩家傷害 ×70」。
- 新增覺醒 Boss 血線無敵：血量低於 80%、60%、40%、20% 時，各觸發一次 10 秒無敵。
- 每個血線門檻只觸發一次，避免玩家進場瞬間把 Boss 打到直接下班。
- 新增覺醒副本壓制：玩家攻速降低 90%。
- 新增覺醒副本壓制：Boss 攻擊無視玩家防禦，直接造成真實傷害。
- 規格套用於現有覺醒副本 Boss：收割試煉者、槍神、魔神、歐爾卡。
- 保留所有既有覺醒狀態、稱號、專武、數值與舊存檔相容。
- 更新版本資訊與 PWA 快取版本。

## 試煉設計理念

覺醒副本不再是「進去、Boss 還沒說話、你已經成功」的觀光通道。

現在 Boss 會在血線處鎖門，玩家攻速會被壓制，Boss 打人也不再被防禦刮掉。這才像試煉，不是天界快速通關櫃台。

## Beta 0.9.11 海域施工重點

海域是《傳承》第三張正式地圖，核心玩法定位為「控制」。本版延續既有森林、沙漠地圖系統，不重寫舊架構，以模組補丁方式新增海域規則，確保舊存檔相容。

- Lv.150 開啟海域。
- 海域怪物免疫冰凍，並擁有 50% 最大生命護盾。
- 潮汐、海浪、深海沉默、深海恐懼構成海域環境壓迫。
- 海域死亡會返回沙漠，而非主城。
