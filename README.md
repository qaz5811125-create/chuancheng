# 傳承 Beta 0.6.0 森林狀態壓迫與優先目標

本版以《傳承 Beta 0.5.9 森林圍攻與蠻牛震盪》為基底修改，保留舊存檔與既有系統，新增森林怪物狀態壓迫、🦖 撕裂無限堆疊、🦕 最大生命回血，以及玩家優先打擊目標系統。

## 更新重點
- 新增玩家優先打擊目標：自動 / 🐇 / 🐂 / 🦖 / 🦕。
- 選擇目標後，玩家普通攻擊、自動攻擊與單體技能會優先打指定怪物；指定怪物不存在時會自動攻擊其他存活怪。
- 新增玩家負面狀態：🥀 虛弱、🌀 混沌、🩸 傷口惡化、🦖 震懾。
- 🐇 森林野兔：普攻造成玩家撕裂與虛弱，成功造成傷害後疊加自身攻速，技能改為閃避本能。
- 🐂 森林蠻牛：保留破防、暈眩與斷連擊定位。
- 🦖 森林暴龍：普攻造成無限堆疊撕裂、降回血與混沌，技能改為震懾讓玩家防禦歸 0。
- 🦕 森林古龍：每秒回復最大血量 5%，普攻 10% 機率造成暈眩，無敵技能維持。
- 保留怪物群共同攻擊、每隻怪物獨立攻擊計時與技能冷卻。
- 保留森林攻速提高與玩家破甲每 10 關重置規則。

## 存檔

- 版本號更新為 Beta 0.6.0。
- 舊存檔若沒有優先目標或新玩家狀態欄位，會自動補上預設值。

# 傳承 Beta 0.5.9 森林圍攻與蠻牛震盪

本版以《傳承 Beta 0.5.8 森林攻速與10關破甲重置版》為基底修改，保留舊存檔與既有系統，新增怪物群共同攻擊與 🐂 森林蠻牛普攻擊暈。

## 更新重點
- 怪物編隊強化：場上所有存活怪物都會依照自己的攻擊速度一起攻擊玩家。
- 每隻怪物使用獨立攻擊計時與技能冷卻。
- 死亡怪物會停止普通攻擊、技能施放與狀態套用。
- 🐂 森林蠻牛普通攻擊新增「震盪撞擊」。
- 震盪撞擊：命中玩家時 15% 機率造成暈眩 3 秒。
- 震盪撞擊內建冷卻 8 秒，暈眩不可疊加，玩家已暈眩時不延長時間。
- 暈眩期間玩家不能手動攻擊、自動攻擊或施放主動技能。
- 暈眩會立即中斷玩家連擊，清空攻擊佇列與連擊節奏。
- 暈眩期間玩家回血照常生效，怪物群仍可繼續攻擊玩家。
- 保留森林攻速提高與玩家破甲每 10 關重置規則。
- 保留 Beta 0.5.8 的世界地圖、森林怪物、玩家血量/防禦/回血、怪物技能與狀態顯示。
- 保留命中特效、連擊、怪物詞綴、掉落、裝備、強化、技能、副本、離線收益與舊存檔相容。

## 存檔
- Save Key 不變，舊存檔可直接延續。
- 版本號更新為 Beta 0.5.9。
- 舊存檔若沒有新欄位，會由既有補欄位邏輯自動處理。

# 傳承 Beta 0.5.8 世界地圖、森林與怪物攻擊系統

本版以 Beta 0.5.7 命中回饋與連擊系統為基底修改，保留舊存檔與既有系統，新增世界地圖、森林地圖、玩家生存屬性與怪物主動攻擊。

## 更新重點
- 新增世界地圖頁籤，顯示森林、沙漠、海域、天域、下獄。
- 森林 Lv50 正式開啟；沙漠 Lv100、海域 Lv150、天域 Lv200、下獄 Lv250 先顯示鎖定與敬請期待。
- 新增森林怪物：🐇 森林野兔、🐂 森林蠻牛、🦖 森林暴龍、🦕 森林古龍。
- 森林 Boss 會隨機出現 🦖 高攻擊高破甲型，或 🦕 高防禦高回血型。
- 新增玩家血量、防禦、回血/秒，初始為 HP 10000、防禦 500、回血 500/秒。
- 玩家血量、防禦、回血可用金幣與能力點升級。
- 新增怪物主動攻擊玩家，怪物攻擊力、破甲與攻速會隨關卡成長。
- 新增怪物技能：狂暴、擊飛、撕咬、無敵。
- 新增玩家狀態：暈眩、撕裂、降防、破甲。
- 玩家暈眩時不能攻擊，且不能回血。
- 玩家血量歸零時會觸發簡易戰鬥失敗流程，重置目前關卡戰鬥。
- 保留 Beta 0.5.7 的命中特效、連擊系統與怪物詞綴系統。
- 保留攻擊、自動攻擊、傷害數字、爆擊、秒殺、狀態、編隊、掉落、裝備、強化、技能、副本、離線收益與舊存檔相容。
