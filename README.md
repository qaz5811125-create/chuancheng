# 傳承 Beta 0.9.22 Hotfix 6【下獄狀態同步】

本版為下獄入口最後修正版，重點修正 Hotfix 5 後「世界地圖顯示目前在下獄，但主畫面仍像主城」的狀態與畫面不同步問題。

## 修正內容

- 下獄誓約進行中但沒有下獄戰鬥時，主畫面不再被當成真正下獄所在地。
- 世界地圖的下獄卡片若偵測到未完成誓約，按鈕改為「繼續」，可直接返回迷宮節點面板。
- 若玩家資料中仍有 p.hell.run，系統會自動同步並開啟下獄迷宮面板。
- 主畫面會顯示「下獄誓約進行中」提示，可繼續或放棄下獄。
- 下獄戰鬥中仍會標記所在地為下獄；非戰鬥節點狀態以迷宮面板承接。
- 保留 Hotfix 5 隨機門資料修正，門仍為 2～3 扇隨機生成。
- 保留攻速 100/秒上限與手機降溫修正。

## 版本定位

這版不是重做下獄玩法，而是把「下獄資料狀態」與「玩家實際看到的畫面」接在一起。
