# 傳承 Beta 0.9.24【終局覺醒與輪迴雛形】

本版以 Beta 0.9.23 Hotfix 2 為底包，補齊第一部最後三個覺醒職業，並建立第二部【輪迴】的可互動雛形。

## 本版重點

- 新增法師覺醒：法師 → 元素師
- 新增刺客覺醒：刺客 → 夜襲
- 新增戰騎覺醒：戰騎 → 守護者
- 戰鐮 9 覺醒條件現在可完整達成
- 輪迴之門進入後不再只是預覽，改為輪迴雛形介面
- 輪迴規則：一條命、一個職業、死亡後重新選職業
- 輪迴職業：技能師、戰鐮、狂戰士、槍手、弓箭手，皆以未覺醒狀態開始
- 輪迴寶箱：可由升級、打怪、副本、隨機事件取得
- 寶箱可用 ×1、×2、×3、×5、×10 開啟
- 技能點升級可用 ×1、×2、×3、×5、×10
- 新增輪迴裝備欄：武器、頭盔、戒指1、戒指2、項鍊、鞋子
- 輪迴地圖：下獄 → 海域 → 沙漠 → 森林 → 主城 → 天域（傳承玩家所在地）
- 每張地圖 30 關，第10/20關為小 Boss，第30關為傳承職業 Boss
- 輪迴階段：亡靈、骨頭、骨頭將士、亡靈總帥、煉獄之神、輪迴者、真•輪迴者
- 真•輪迴者 / 遠古階會受到傳承壓制，所有屬性 -5%

## 保留內容

- Beta 0.9.23 Hotfix 2 的能力點倍率降載
- 戰鐮試煉降難
- 輪迴月圓稱號
- 輪迴之門入口
- 逐日者覺醒與紅色稱號修正
- 已覺醒職業收納整理
- 下獄 Hotfix 6 狀態同步
- 攻速 100/秒上限與手機降溫保護

## 注意

第二部【輪迴】目前是雛形版本，用於測試核心循環：選職業、推關、開寶箱、升技能點與裝備欄。後續仍可繼續擴充輪迴覺醒條件、輪迴職業被動、正式 Boss 數值與結局演出。
