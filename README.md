# 傳承 Beta 0.9.0 深淵與神器系統

本版以 Beta 0.8.0 天災一擊冷卻熱修為基底，整合深淵模式、神器系統與玩家生存補強。

## 核心內容

- 中毒層數會壓制目標回血：每層降低 0.1%，最高 100%。
- 新增吸血效果，普通攻擊 30% 機率吸取自身攻擊 50% 的血量。
- 新增 Lv35 技能「淨化」，可移除非控制負面效果，但不能解除暈眩。
- 新增 Lv45 技能「血盾」，護盾值為玩家最大血量 30%，可擋物理與狀態傷害，真實傷害穿透。
- 戰士、狂戰士、戰騎新增「不屈意志」，血量歸零時 5 秒無敵、回血 +500%，冷卻 90 秒。
- 關卡達到 80 後開啟深淵模式。
- 通關深淵第 1 層開啟神器系統。

## 神器

神器每次只能選擇 1 個生效，並且等級獨立。

- 阿爾巴克神劍：深淵第 5 層解鎖，傷害 +500%，可升級，每級 +25%。
- 托尼亞聖弓：深淵第 20 層解鎖，攻速 +50%，原本具備普攻群體打擊的職業群體打擊機率 +10%，不可升級。
- 彎托沙兵盾：深淵第 45 層解鎖，護盾 +500,000、血量 +5,000,000，可抵擋真實傷害，可升級，每級護盾 +50,000、血量 +100,000。

## 深淵 Boss

深淵 Boss 無回血效果，但具備高血量與高防禦。普攻附帶中毒、撕裂、破甲與少量擊暈，技能「貫穿」造成最大生命 20% 真實傷害。
