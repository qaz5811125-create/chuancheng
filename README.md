# 傳承 Beta 0.9.2 技能師七選一測試版

本版基於 Beta 0.9.1 召喚師戰鬥熱修版，新增「浮空」玩家狀態與「技能師 / 傳說」職業。

重點：技能師關閉普攻，改用特殊狀態傷害；每次攻擊只會從 7 種狀態中隨機選 1 種施加；低血量自動浮空免疫並回血；專武魔法手套會讓本次被選中的狀態堆層翻倍。

# 傳承 Beta 0.9.1 大型系統修正版

本版以 Beta 0.9.0 平衡修正版為基底，加入大型平衡與系統更新。

## 更新重點

- 血盾：玩家血量剩 10% 以下時自動觸發。
- 淨化：玩家身上 2 個以上負面效果時自動觸發。
- 裝備副本：60 關解鎖。
- 強化石礦坑：70 關解鎖。
- 裝備強化：只有 +10、+20 等十階突破需要強化石，其餘只消耗金幣。
- 新增永恆品質裝備，彩色顯示，基礎掉率 0.01%。
- 新增存檔備份與匯入。
- 深淵不再顯示倒數 0 秒，無挑戰時間限制。
- 神器強化只消耗金幣。
- 怪物面板加大，降低狀態顯示造成的畫面跳動。

## 新增抽獎

### 傳承祭壇

- 1 抽：100 傳承之魂。
- 10 連抽：900 傳承之魂。
- 100 連抽：9000 傳承之魂。

### 職業獎池

- 1 抽：50 傳承之魂。
- 10 抽：450 傳承之魂。
- 100 抽：4500 傳承之魂。
- 可取得一般、一般↑、稀有、稀有↑、史詩、史詩↑、傳說、傳說⭐、傳說⭐⭐、傳說⭐⭐⭐升級碎片。

## 新增職業

- 盜賊：偷取目標增益，攻速提升。
- 槍手：燃燒爆發、低攻速、高秒殺機制。
- 聖錘兵：護盾、暈眩、低攻速。
- 巨神兵：超高生存能力，低攻速，普攻造成最大生命傷害。

## 英雄系統

Lv250 開啟。英雄化身持續 60 秒，共用冷卻 120 秒。

- 絕對維度•利克雅：魔法師定位，普攻暈眩，死亡牢籠造成最大生命 90%。
- 死亡之神•杜里恩：收割定位，普攻放大負面狀態，地獄枷鎖有機率使目標逃離。
