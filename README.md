# 傳承 Beta 0.9.22 Hotfix 5【下獄門資料接回】

這版是下獄入口最後一次保守修補。

## 修正內容

- 重新接線下獄誓約按鈕，點擊後直接建立本次下獄 run。
- 強制生成 2～3 扇隨機門。
- 門資料同步寫入 `p.hell.run.doors`、`p.hell.doors`、`p.hell.currentDoors`。
- 若門資料被舊流程洗掉，Hotfix5 會自動重新接回並重畫下獄面板。
- 進入門前會再次修復 run / doors，避免 `verify-no-doors`。
- 地圖仍維持隨機，不固定路線。
- 保留 Hotfix 1 的攻速 100/秒上限與手機降溫保護。

## 版本定位

不是重做下獄玩法，而是把隨機門產生器接回畫面與下獄 run 的資料管線。
