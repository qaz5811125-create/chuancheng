# 傳承 Beta 0.5.7 命中回饋與連擊系統

本版以 Beta 0.5.6 為基底修改，方向從修復手持武器揮擊改為穩定的命中回饋與戰鬥可玩性。

## 更新重點
- 停用舊玩家手部、武器揮擊、劍氣與全域攻擊動畫層顯示邏輯。
- 攻擊成功後直接在目前目標附近播放命中特效，不依賴手部圖片、武器圖片或複雜全域座標。
- 新增普通命中、爆擊、秒殺、技能攻擊的不同打擊特效。
- 新增連擊系統：命中累積，3 秒未命中會中斷，10 / 50 / 100 / 300 連擊會出現提示。
- 新增連擊加成：依連擊階段提升傷害、爆擊率與攻速，連擊中斷後加成消失。
- 新增怪物詞綴系統：普通怪、精英怪與 Boss 生成時可獲得狂暴、硬皮、閃避、寶藏、詛咒、堅韌、易燃、破甲等詞綴。
- 詞綴會顯示在怪物名稱旁、目前目標資訊與編隊列表中。
- 保留攻擊、自動攻擊、傷害數字、爆擊、秒殺、狀態、怪物編隊、掉落、裝備、強化、技能與舊存檔相容。

## 存檔
- Save Key 不變，舊存檔可直接延續。
- 版本號更新為 Beta 0.5.7。
