# 傳承 Beta 0.9.23【逐日者覺醒】

本版以 Beta 0.9.22 Hotfix 6【下獄狀態同步】為底包，新增弓箭手覺醒路線。

## 逐日者

弓箭手覺醒為逐日者後，普攻會圍繞天災一擊展開：

- 普攻後下一下必定觸發天災一擊。
- 普攻累積 100 次觸發天災驚變，造成玩家傷害 ×91000%。
- 普攻 33% 觸發逐日猜拳。

## 覺醒條件

1. 弓箭手職業等級達到 10 等。
2. 觸發 50 次天災一擊。
3. 通關【逐日記】。

## 覺醒副本【逐日記】

Boss：后羿

Boss 被動：

- 免疫天災一擊。
- 每 3 秒回復 1% 最大生命。
- 攻擊提升 ×700%。

通關後獲得紅色稱號【一箭看不見】。

## 逐日猜拳

普攻時有 33% 機率觸發，觸發後三選一：

- ✌🏻：造成玩家傷害 ×10000。
- ✊🏻：吸收護盾 = 玩家目前護盾 ×1000%。
- 🖐🏻：格擋傷害一次，可堆疊。

## 專屬神器與專武

- 后羿的那拔弓：逐日者普攻可對場上所有怪物造成傷害。
- 后羿的拖鞋：閃避率 +60%。

## 兼容性

保留既有存檔與 Beta 0.9.22 Hotfix 6 的下獄修正，不重寫原本戰鬥系統。
